🔐 Instalar el certificado QA (quita el aviso + habilita la cámara)

🍏 iPad / iPhone (Safari)

  1. Abre esta página en Safari y toca ⬇️ Descargar certificado QA → Permitir.
  2. Ajustes → General → VPN y gestión de dispositivos → toca el perfil → Instalar.
  3. Ajustes → General → Información → Ajustes de confianza de certificados → activa "Caddy Local Authority".
  4. Abre https://172.31.98.50:8446/login → candado válido → la cámara del waiter funciona.

🤖 Android (Chrome)

  1. Toca ⬇️ Descargar certificado QA → Ajustes → Seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA.
  2. Atajo: basta aceptar "La conexión no es privada → Continuar" una vez.
