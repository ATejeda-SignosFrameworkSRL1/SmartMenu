🔐 Instalar el certificado QA (quita el aviso + habilita la cámara)

🍏 iPad / iPhone (Safari)

  1. Abre esta página en Safari y toca ⬇️ Descargar certificado QA → Permitir.
  2. Ajustes → General → VPN y gestión de dispositivos → toca el perfil → Instalar.
  3. Ajustes → General → Información → Ajustes de confianza de certificados → activa "Caddy Local Authority".
  4. Abre https://172.31.98.87:8446/login → candado válido → la cámara del waiter funciona.

🤖 Android (Chrome)

  1. Toca 🤖 Android — descargar CA. Se guarda en Descargas.
  2. NO uses "abrir" en la notificación de descarga: desde Android 7 el sistema ya no instala certificados así y Chrome responde "this file doesn't exist anymore" aunque el archivo esté bien.
  3. Ve a Ajustes → Seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA, acepta la advertencia y busca el archivo en Descargas.
  4. Hace falta tener PIN o patrón en el equipo: Android no instala CAs sin bloqueo de pantalla.
  5. Sin la CA instalada el navegador no registra el service worker, así que no aparecerá "Instalar aplicación" ni funcionará la cámara del waiter.
